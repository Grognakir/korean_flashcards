# Локальные материалы для аудирования (не в git)

Эта папка — для личных материалов TOPIK I, которые не публикуются вместе с
приложением (репозиторий публичный, деплоится на GitHub Pages, а официальные
записи и тексты TOPIK — это материалы NIIED, защищённые авторским правом).
Всё, что здесь лежит (кроме этого файла), в `.gitignore` и никогда не попадёт
в git/на сайт — работает только локально, у вас на компьютере.

## Откуда взять материалы

Официально и бесплатно: **topik.go.kr** → «학습하기» (Study TOPIK) →
«학습자료실» (Learning Archive) — там выкладывают прошлые тесты: аудио для
аудирования, PDF с текстами, ответы.

## Что сюда положить

```
data/local/
  listening.json   — вопросы аудирования (см. схему ниже)
  audio/           — сами mp3-файлы, скачанные с topik.go.kr
```

## Схема `listening.json`

Плоский массив объектов, `audio` — путь до файла в `audio/` относительно корня
приложения:

```json
[
  {
    "audio": "data/local/audio/64-1.mp3",
    "question": "다음을 듣고 맞는 답을 고르십시오.",
    "options": ["...", "...", "...", "..."],
    "correct": "...",
    "id": "lis0"
  }
]
```

После того как файл появится и в нём будет хотя бы один вопрос, во вкладке
«Экзамен» появится раздел «Аудирование» — на публичном сайте без этих файлов
он просто не показывается.
