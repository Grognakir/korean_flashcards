# Локальные материалы для аудирования (не в git)

Официальные записи и тексты TOPIK — материалы NIIED, защищённые авторским
правом. `listening.json` и `audio/` — в `.gitignore`, никогда не попадают в
git/на сайт, работают только локально. `reading.json` — исключение: он
содержит только текст вопросов (без аудио) и коммитится в публичный
репозиторий, поэтому раздел «Чтение TOPIK» доступен и на проде.

## Откуда взять материалы

Официально и бесплатно: **topik.go.kr** → «학습하기» (Study TOPIK) →
«학습자료실» (Learning Archive) — там выкладывают прошлые тесты: аудио для
аудирования, PDF с текстами, ответы.

## Что сюда положить

```
data/local/
  listening.json   — вопросы аудирования, не коммитится (см. схему ниже)
  reading.json      — вопросы чтения TOPIK, коммитится (публичный)
  audio/           — сами mp3-файлы, скачанные с topik.go.kr, не коммитится
```

## Схема `listening.json`

Плоский массив объектов, `audio` — путь до файла в `audio/` относительно корня
приложения:

```json
[
  {
    "audio": "data/local/audio/64-1.mp3",
    "question": "다음을 듣고 맞는 답을 고르십시오.",
    "options": ["...", "...", "...", "..."],
    "correct": "...",
    "id": "lis0"
  }
]
```

После того как файл появится и в нём будет хотя бы один вопрос, во вкладке
«Экзамен» появится раздел «Аудирование» — на публичном сайте без этих файлов
он просто не показывается.
