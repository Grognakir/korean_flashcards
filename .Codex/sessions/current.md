# Контекст сессии — Korean Flashcards

Последнее обновление: 2026-08-17

## Чем занимаемся

Проектируем персональный прогресс с авторизацией, синхронизацией между устройствами и интервальными повторениями для слов, грамматики и тематических упражнений. Система должна реже показывать уверенно освоенное и отдавать приоритет новым, слабым и просроченным элементам.

## Принятые решения

- Варианты в этапах «слово → перевод», «перевод → слово» и «предложение: выбор слова» берутся только из `state.session.wordSet`.
- Антонимы и синонимы появляются только тогда, когда оба слова входят в карточки текущей Сессии; все отвлекающие варианты также ограничены этим набором.
- Грамматический этап строится по примерам и формам слов из карточек текущей Сессии, максимум пять заданий.
- Ограничение действует в режимах «По этапам» и «Вперемешку».
- Для зонтов, карандашей, ручек и ножей принимаются `자루` и `개`; для таблеток — `정` и `알`.
- В заданиях на выбор русский контекст показывается до ответа, если от него зависит выбор счётного слова.
- Для текущей статической SPA рекомендуемый бэкенд — Supabase Auth + Postgres с RLS; приложение остаётся на GitHub Pages.
- Расписание хранится отдельно для каждого пользователя и учебного элемента, а история каждого ответа — отдельным журналом.
- В Сессии сначала выбираются слабые и просроченные элементы, затем новые, после них — давно не повторявшиеся освоенные.
- Оценку слова для интервального алгоритма нужно агрегировать по всей Сессии, чтобы несколько упражнений с одним словом за один день не увеличивали интервал искусственно.

## Открытые задачи

- [ ] Реализовать вход и регистрацию только по логину и паролю; email не показывать и не запрашивать.
- [ ] Создать проект Supabase и предоставить URL проекта и publishable key для подключения клиента.
- [ ] Реализовать таблицы прогресса и истории ответов, RLS, авторизацию, миграцию `progress-v2` и отбор Сессии по сроку повторения.
- [ ] При необходимости заменить одно из дублирующих заданий `cnt11`/`cnt27` новым примером.
- [ ] Исправить русское согласование в `cnt57`: «две хризантемы».

## Контекст для следующей сессии

Сейчас `app.js` сохраняет только `known/learning` в `localStorage` под ключом `progress-v2`; ошибки повторяются лишь внутри текущего прохода через временную очередь `retry`. Пользователь выбрал регистрацию по логину и паролю без email. Так как Supabase Password Auth требует email или телефон, интеграция должна незаметно преобразовывать нормализованный логин в стабильный технический email; подтверждение email отключается, восстановление пароля в первой версии отсутствует. Для Claude подготовлено отдельное задание на UI, для Cursor — на Supabase, RLS, FSRS, синхронизацию и интеграцию. Каталог `.claude/sessions/` не изменялся.
