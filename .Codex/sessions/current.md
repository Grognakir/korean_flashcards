## Чем занимаемся

В `app.js` добавлен режим «Пробный экзамен» для последовательного прохождения одного TOPIK I с раздельной статистикой по аудированию и чтению.

## Принятые решения

- Новый режим реализован как независимая ветка состояния и не изменяет существующий раздел «Экзамен».
- Список экзаменов строится по данным чтения; при отсутствии локального аудирования экзамен сразу начинается с чтения.
- Вопросы сортируются по числовому номеру из `id`, без перемешивания.
